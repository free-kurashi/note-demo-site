# note 公式への確認文案

他人の記事を note 公式の埋め込みカードで並べるサイトを運営してよいか、note サポートへ確認するための文案。
【】の箇所は送付前に埋める。背景は README の「note の埋め込みと規約(確認結果)」「他人の記事のリンクを貼る場合の懸念点」を参照。

## 文案

**件名**: 【確認】noteの記事を外部サイトに埋め込み(「サイトに貼る」)で一覧表示するサービスについて

**本文**

お世話になっております。note ID【witty_minnow853】の【お名前】です。
noteの記事を外部サイトで紹介することについて、規約上の取り扱いを確認させてください。

**【作ろうとしているサイトの概要】**

100円の有料noteを読んだ記録をまとめるサイトです(サイトURL: 【URL】)。

- 読んだnoteを、note公式の埋め込み(記事の「…」→「サイトに貼る」と同じ iframe)で一覧に並べます。記事本文は私のサイトには保存せず、タイトルなどの情報も自前で保持しません。
- 各記事に、私の感想と、読者が自己申告で入力する購入額・tips額・感想を併記します。これらは note 上の実績ではなく、自己申告の値であることを明記します。
- 現在は非営利で、広告などは入れていません。件数は最大100件程度です。
- 現状は、私自身の記事のみで動作確認しています。

**【ご質問】**

1. 公式の埋め込み(iframe)を使って、**他のクリエイターの記事も含めて**、私が運営する外部サイトに一覧表示することは、規約上問題ありませんか。
2. 有料記事を埋め込んだ場合に表示されるカードの範囲(無料部分のみか)は、購読契約の範囲を超えない扱いでしょうか。
3. 「外部サイトへの配信を許諾する」設定は、埋め込みの表示に影響しますか。許諾しない設定のクリエイターの記事を埋め込むと、どうなりますか。
4. 記事ごとに、自己申告の購入額・tips額と、第三者(読者)の感想を併記することに、制約や注意点はありますか。
5. 他のクリエイターへの事前連絡や許可は必要ですか。公式の埋め込み機能の範囲であれば不要、という理解でよいでしょうか。
6. 将来、広告やアフィリエイトなどで収益化する場合に、制約はありますか。
7. 件数(最大100件程度)や表示方法(遅延読み込み)について、サーバー負荷の観点で配慮すべき点はありますか。

ご多忙のところ恐れ入りますが、ご確認をお願いいたします。

【お名前 / 連絡先】
