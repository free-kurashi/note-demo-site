# 読了の循環(デモ)

読んだ100円noteを note 公式の埋め込みカードで並べ、読了のたびに「作品」が育つサイト。

## 登録のしかた(サイト主)

Notion にデータベースを1つ作り、次のプロパティを用意します(名前は完全一致)。

| プロパティ名 | 種類 | 内容 |
|---|---|---|
| (任意の名前) | タイトル | メモ用 |
| `noteのリンク` | URL | 例: https://note.com/xxx/n/nxxxxxxxxxxxx |
| `購入額` | 数値 | サイト主が購入した額(円) |
| `tip額` | 数値 | サイト主が贈ったtip額(円) |
| `感想` | テキスト | サイト主の感想(カードの「サイト主の感想」ボタンで表示) |

行を追加すると、最大30分後にサイトの一覧へ反映されます(GitHub Actions が取り込みます)。

### 初回設定

1. https://www.notion.so/profile/integrations で「内部インテグレーション」を作成し、シークレットをコピー
2. 作成したデータベースの「…」→「接続」から、そのインテグレーションを追加
3. データベースのURL `notion.so/<ワークスペース>/<32桁のID>?v=...` の32桁がデータベースID
4. GitHub のこのリポジトリ → Settings → Secrets and variables → Actions に登録
   - `NOTION_TOKEN` = シークレット
   - `NOTION_DATABASE_ID` = 32桁のID

未設定の間は、`public/entries.json`(コミット済みの初期データ)を表示します。

## 閲覧者のアクション

各カードの「閲覧者のアクション」から購入額・チップ額を入力でき、トップの合計に(サイト主の金額とは別枠で)加算されます。
デモ版では入力はその端末のブラウザにだけ保存され、他の閲覧者とは合算されません(全員分の集計には Cloudflare Pages + D1 などサーバー側が必要)。

## 開発

```
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に出力
```
