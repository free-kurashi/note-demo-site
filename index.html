    読了の循環(デモ画面)

    これはデモ画面です。表示されている感想・金額・パズルの進み具合は、動作を見せるためのサンプルであり、実際のコメントや実際の購入・チップとは無関係です。

    記事カードは note 公式の埋め込みで、記事自体は実在します。一方、サイト主の感想・購入額・tips額・読者の感想と金額はすべてデモ用のサンプルです(本番では、サイト主が Notion に入力した内容と、読者が実際に入力した内容を表示する予定です)。読者のアクションとして入力した内容は、この端末のブラウザにだけ保存され、他の人には表示されません。

    このサイトの使い方

    どんなサイト?

    読んだ note と、そこで感じたことを集めるサイトです。感想が1つ書かれるたびに、世界地図のジグソーパズル(全100ピース)が1ピースずつ埋まり、みんなの感想が集まるほど地図が完成に近づきます。画面の上には、note に使われたお金の合計も表示されます。

    想定している使い方

    • サイト主: 読んだ note を登録して、感想と、購入した金額・チップの金額を残します。
    • 読者(ここを見に来た人): 気になった note を読んで、感想や、購入した金額・チップの金額を残せます。

    はじめての方へ: 3ステップ

    1. note を読む下の「読んだnote」に並んでいるカードの「noteで開く ↗」を押すと、本物の記事が開きます。
    2. 「読者のアクション」を押すカードの緑のボタンです。お名前(空欄でもOK)、購入した金額、チップの金額、感想を入れて「記録する」を押します。
    3. パズルを見る感想を書くと、パズルのピースが1つ埋まります。どこが埋まるかはランダムです。あわせて、上の金額にも加算されます。

    ※金額だけを入れて感想を空にすると、金額は加算されますが、ピースは埋まりません。

    ほかのボタン

    • サイト主の感想: サイト主が書いた感想を読めます。
    • 読者の感想: 読者の感想を、1人ずつ「前の人 / 次の人」で読めます。
